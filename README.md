# ShopSphere – Product Listing Web App

1. Project Overview

ShopSphere is a responsive web application that displays products using a public API. Users can search, filter, and sort products dynamically. The project demonstrates JavaScript concepts, API integration, and UI development.


2. Purpose

* Fetch and display data from an API
* Implement search, filtering, and sorting
* Build a responsive user interface
* Practice clean and modular code


3. API Used

FakeStore API
https://fakestoreapi.com/product

It provides product title, price, category, image, and description.


4. Features

* Search products by name
* Filter by category
* Sort by price (low to high, high to low)
* Responsive design for all devices


5. Technologies Used

* HTML
* CSS
* JavaScript (ES6)
* Fetch API
